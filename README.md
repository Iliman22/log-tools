# log-tools

Simple Python utilities for parsing and analyzing log files.  
Created for educational use and practice with Git, GitHub, and basic log analysis.

## Features
- Read and clean log files
- Extract IP addresses and timestamps
- Count errors and warnings
- Export simple analysis reports

## Files
| File | Description |
|------|--------------|
| `parser.py` | Main Python script for log parsing |
| `sample.log` | Example log file |
| `report.md` | Example analysis report |

## Usage
Run the parser in your terminal:
```bash
python parser.py sample.log
